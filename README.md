# Cassette

An Android app built with Kotlin and Jetpack Compose.

## Requirements

- Android Studio (latest stable)
- JDK 11
- Android SDK 37 (compile/target), min SDK 24

## Getting started

```bash
git clone <repo-url>
cd Cassette
./gradlew build
```

Or open the project directly in Android Studio and run the `app` configuration.

## Project structure

```
app/
  src/main/java/com/ruidoespontaneo/cassette/   # App source
  src/main/res/                                 # Resources
  src/test/                                     # Unit tests
  src/androidTest/                               # Instrumented tests
```
